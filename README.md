# Retail Sales Performance Analysis & Business Intelligence Dashboard

End-to-end Data Analytics project analysing retail transaction data using **Excel, Python, SQL Server and Power BI**.

This project demonstrates a complete analytics workflow from data validation and cleaning through SQL analysis and interactive dashboard development.

## Dashboard Preview

![Retail Sales Dashboard](screenshots/powerbi/power_bi_full_dashboard.PNG)

## Business Problem

A retail company wants to understand its sales performance,
profitability, regional performance and product performance
to support better business decisions.

## Objectives

- Analyse sales trends.
- Identify top-performing categories.
- Evaluate regional performance.
- Assess profitability.
- Build an interactive Power BI dashboard.

## Key Findings

- Technology generated the strongest sales and profit performance.
- The West region delivered the highest overall profit.
- Higher discounts generally reduced profitability.
- Sales increased during year-end periods, indicating seasonal demand.

## Business Recommendations

- Prioritise high-performing categories.
- Review discount strategies for low-margin products.
- Optimise inventory and promotions using seasonal trends.
